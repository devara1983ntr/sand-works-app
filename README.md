# SAND WORKS

**SAND WORKS** — an online-first Android application for small farming/labour operations. One owner runs tractors, drivers and daily labourers on trips, tracks money accruals transparently, and keeps everyone informed.

This repository is the **complete product + technical specification** for the SAND WORKS native app. It is documentation only — it contains no application source code.

## Status
- Product direction: **online-first** (Firebase backend). Not offline-first, and not derived from any prior/legacy application.
- Scope: **private, family/operator tool** for one organisation. No public store marketing requirement.
